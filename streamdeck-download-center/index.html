How it works

Set up in three steps

1

Install Stream Deck Android

Download the APK and install it on your Android device.

2

Install Windows Companion

Run the Companion on the Windows PC you want to control.

3

Pair both devices

Connect to the same Wi-Fi network, discover the PC and approve the pairing.

Installation guide

Get connected

Android

  1. Download the APK.
  2. Install the APK.
  3. Open Stream Deck.
  4. Allow required permissions if requested.

Windows

  1. Download Windows Companion.
  2. Install or run it.
  3. Keep Companion running.
  4. Open Stream Deck on Android.
  5. Pair the device on the same local network.
